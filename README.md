# 🚂 Thiệp Điện Tử 20/11 — Chi Đội 6/10 | Trường THCS Dũng Sĩ Điện Ngọc

Dự án React + TypeScript + Vite + TailwindCSS v4 thiết kế Thiệp Điện Tử chào mừng Ngày Nhà Giáo Việt Nam 20/11 của **Chi đội 6/10 — Trường THCS Dũng Sĩ Điện Ngọc** (GVCN: **Cô Nguyễn Minh Quyên**, Sĩ số: **40 học sinh**).

---

## 🚀 Cách Chạy Dự Án Trên Máy Tính

Mở Terminal tại thư mục `d:\projects\thiep-20-11-lop-6-10` và chạy:

```bash
npm run dev
```

Sau đó mở trình duyệt tại địa chỉ `http://localhost:5173`.
